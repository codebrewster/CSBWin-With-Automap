# Visibility regression tests: what the map counts as seen from where the party stands.
# Run with "make visibility-test" in src (needs the game data and the save in Dungeons/Dungeonmaster).
#
# Coordinates as the map shows them: L<level> (<x>,<y>), the title of the map's right-click menu.
# Light is the palette index of the map's debug light: 0 full light .. 5 darkest.
# An item is named as the game shows it ("Scroll", any case), with its corner of the tile
# (NW, NE, SE, SW) when two items there share the name; without either, a check judges the
# tile's items together: seen when any of them is.
# An item in an alcove (the Vi altar too) is checked as the alcove, by its wall face: the map
# remembers what an alcove holds per face, not per item.
# A tile is the cell itself, floor or wall, seen when the map's fog shows it: in the line of
# sight and within the light's reach.
# A save line starts a section: the cases below it, up to the next save line, are drawn in that
# saved game (in Dungeons/Dungeonmaster). Each save is loaded by a run of its own.
# A case without checks is a survey: the run prints a check line for every thing the frame drew,
# with the numbers it was judged by, to compare with the screen and paste here.
